# External Q-Data Validation

This package reproduces selected source Q-methodology analyses before any Q-AI extension is tested. The primary study is Pidgeon (2025), DOI `10.25946/30122956.v1`.

Repository: <https://github.com/tiamole/q-ai-external-validation>

## Current status

- Protocol v1.0 frozen locally before computational reproduction.
- Repository source files authenticated against repository MD5 values.
- Original files preserved read-only under `data/original/pidgeon-2025/`.
- Pidgeon workbook schema and the single prespecified repair are recorded in `config/frozen-analysis.yml`.
- Source loadings, eigenvalues, variance, primary-factor assignments, and all 225 factor-array scores reproduce within the frozen exact-numerical criteria.
- All 29 source-marked distinguishing-statement directions agree.
- Overall source-study classification: **exact numerical reproduction**.
- Prespecified Stage D robustness analysis completed for PCA and centroid extraction.
- Parallel analysis and maximum-acceleration scree analysis both support two components.
- Five-factor robustness classification: **fragile solution** for both extraction methods.
- Factor interpretability remains pending independent assessment.

This local freeze is an auditable timestamped analysis-plan freeze, not a claim of registration in an external preregistration service.

## Claim boundary

Results may reproduce, corroborate, or stress-test selected computational Q-AI operations. They cannot validate the Q-AI framework as a whole or establish educational, causal, or human-AI collaboration effects.

## Package map

```text
protocol/       Frozen protocol, robustness addendum, seeds, and freeze records
data/original/  Downloaded read-only repository artifacts (not committed)
data/normalized Script-generated analysis inputs
data-manifest/  Source provenance, checksums, and decisions
config/         Frozen study settings
src/            Reproduction scripts
outputs/        Script-generated integrity and reproduction results
```

All normalized data and result tables must be generated by scripts. Manual spreadsheet edits are prohibited. Upstream workbooks and the thesis PDF are excluded from Git and restored from their repository URLs by `src/download_sources.py`; every download must match its frozen byte count and SHA-256 hash.

## Reproduce From a Fresh Clone

Python 3.14 is the tested environment. From PowerShell:

```powershell
git clone https://github.com/tiamole/q-ai-external-validation.git
Set-Location q-ai-external-validation
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --requirement requirements-lock.txt
.\.venv\Scripts\python.exe src\download_sources.py
.\.venv\Scripts\python.exe src\validate_inputs.py
.\.venv\Scripts\python.exe src\reproduce_source.py
.\.venv\Scripts\python.exe src\robustness.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py' -v
.\.venv\Scripts\python.exe src\verify_checksums.py
```

The GitHub Actions workflow executes the same sequence on `windows-latest`. Committed outputs are byte-checksummed as the frozen reference snapshot. Fresh runs are checked against the prespecified scientific result contract because last-bit floating-point serialization can vary across BLAS builds.
