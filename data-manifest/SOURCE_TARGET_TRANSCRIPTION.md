# Pidgeon Source-Target Transcription

The factor-array reference records the statement IDs and integer score columns displayed in thesis Figures 6.3-6.7 (printed pages 159, 162, 167, 170, and 175). The distinguishing-statement reference records the `D` and `D*` marks and higher/lower table sections in Tables 6.4, 6.6, 6.8, 6.10, and 6.12.

These are human-readable source targets transcribed from the archived, checksum-verified thesis PDF. They are not analytic outputs. The reproduction script validates each factor's 45 unique statement IDs and forced distribution before comparison.

The array transcription received an independent computational cross-check: using the published loading table, primary-factor assignment by maximum absolute loading, and standard Q weights `loading / (1 - loading^2)` reconstructs all 225 integer scores exactly.

The thesis reports no consensus statements for the five-factor solution in Table 6.1. Its statement that 32 Q-sorts are significant cannot be mapped reliably to participant identities because the relevant Table 6.2 distinctions are conveyed partly by color; this limitation remains explicit in the reproduction report.
